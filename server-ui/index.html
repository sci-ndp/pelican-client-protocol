STOMP Server UI

Server-side observer and publisher. The actual STOMP server remains the separate container listening on port 8080; this UI connects as an inspection subscription and auto-ACKs every message, so it stays compatible with the message-queue app's ack-gated delivery. If the server was started with --htpasswd, fill in Username/Password to authenticate.

Transport and negotiation

1. HTTP — browser requests WebSocket Upgrade
2. HTTP 101 — server accepts the protocol upgrade
3. WebSocket — bidirectional transport is open
4. STOMP 1.2 — CONNECT / CONNECTED / SUBSCRIBE
5. Heartbeats — LF frames keep the connection alive
